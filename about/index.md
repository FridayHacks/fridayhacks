Friday Hacks is a technical playground for experimenting with technologies, documenting the journey, and sharing discoveries with the community. The core philosophy is learning by building - from quick weekend hacks to more substantial implementations.

## What You'll Find Here

* **AI/ML Experiments** - LLM integrations, AI-assisted development, agent-based systems
* **Developer Tools** - CLI utilities, automation scripts, productivity hacks
* **Web Development** - Modern frameworks, static sites, API integrations
* **Infrastructure** - Self-hosting, monitoring, CI/CD workflows
* **Project Write-ups** - Detailed breakdowns of hackathon projects and experiments

## The Philosophy

Every project here follows a simple principle: build to learn. Some are weekend hacks that take a few hours. Others are deeper explorations that span weeks. The goal is always the same - get hands-on with new technology and share what works (and what doesn't).

The site has been running since 2015, with topics evolving from terminal customization and security tools to AI agents and real-time dashboards.
