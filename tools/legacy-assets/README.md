# Archived theme tooling

These are the original HPSTR Grunt manifest and configuration, preserved for
reference. They are not part of the Jekyll production build. Their old image
dependencies fail on modern Node versions and require modernization before reuse.

The files were moved out of the repository root because Cloudflare automatically
installed their dependencies before running Jekyll. Keep the production build
root at the repository root, and publish the already committed theme assets.
This directory is excluded from Jekyll output. Grunt paths still reflect the
original repository-root location; relocation is archival, not a supported asset
build command.
